## Key Findings & Recommendations for "Tov AI Clone"

**Best picks for building a marketing-focused AI clone:**

1. **MirrorMind** (SimoxRide/MirrorMind) — Most complete persona framework: style profiling, knowledge graph, testing lab, API deployment, multi-platform extensions. MIT license. **Strongest candidate.**

2. **CloneMe** (vibheksoni/cloneme) — Lightweight, multi-platform, memory-driven. Good for Discord/messaging marketing.

3. **Real-Time-Voice-Cloning** (CorentinJ) — 60K stars, proven tech. Pair with VoiceStudio/OmniVoice for local voice cloning.

4. **VoiceStudio/OmniVoice-Studio** — Best local ElevenLabs alternative. 646 languages, video dubbing, OpenAI-compatible API. 4-8 GB VRAM.

5. **claude-email** (AgriciDaniel) — 116 stars, full email marketing workflow with voice matching. MIT.

6. **ghost-writer** (OneSpiral) — Best writing style clone tool, 24-dimension forensic analysis.

**VRAM reality check:** Most repos are API-based (no VRAM needed). Local LLM running needs ~6-8 GB VRAM for Qwen3/Llama 3.1-class models. Voice cloning needs ~4-6 GB GPU. For a marketing clone, API-based approach (OpenAI/Claude/Groq) is the pragmatic path — local only if privacy/price demands it.

**Gaps found:** No single repo combines voice + writing style + social posting + email in one package. The "Tov AI Clone" will need to be assembled from these components.
